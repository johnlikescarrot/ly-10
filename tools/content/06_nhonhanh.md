==PHẦN F – TRANG NHỚ NHANH TRƯỚC GIỜ THI==

=F.1. Bảng tổng hợp công thức=

--A. Động học cơ bản (ĐV 2.1 – 2.2)--

| Đại lượng | Công thức | Ghi chú |
| Tốc độ trung bình | v = s / t | vô hướng, không âm |
| Vận tốc trung bình | **v** = **d** / t | vectơ, hướng theo **d** |
| Vận tốc tức thời | **v**_t = Δ**d** / Δt (Δt rất nhỏ) | số chỉ của tốc kế |
| Công thức cộng vận tốc | **v**₁,₃ = **v**₁,₂ + **v**₂,₃ | cộng **có hướng** |
| Hai vận tốc cùng phương, cùng chiều | v = v₁ + v₂ | |
| Hai vận tốc cùng phương, ngược chiều | v = hiệu hai độ lớn v₁ và v₂ | hướng theo vận tốc lớn hơn |
| Hai vận tốc vuông góc | v = √(v₁² + v₂²); tan α = v₂/v₁ | |
| Đổi đơn vị | 1 m/s = 3,6 km/h | chia cho 3,6 để đổi km/h → m/s |

--B. Gia tốc và chuyển động thẳng biến đổi đều (ĐV 2.4 – 2.5)--

| Đại lượng | Công thức | Dùng khi |
| Gia tốc | a = Δv / Δt = (v – v₀) / (t – t₀) | luôn |
| Vận tốc theo thời gian | v = v₀ + a·t | thiếu s |
| Quãng đường | s = v₀·t + ½·a·t² | thiếu v |
| Phương trình toạ độ | x = x₀ + v₀·t + ½·a·t² | có gốc toạ độ |
| Công thức độc lập thời gian | v² – v₀² = 2·a·s | thiếu t |
| Vận tốc trung bình | v̄ = (v₀ + v) / 2 | **chỉ** dùng cho CĐT BĐĐ |
| Quãng đường trong giây thứ n | Δsₙ = v₀ + ½·a·(2n – 1) | bài toán "giây thứ n" |

--C. Rơi tự do (ĐV 2.6) – thay v₀ = 0 và a = g vào bảng B--

| Đại lượng | Công thức |
| Vận tốc | v = g·t |
| Độ cao / quãng đường rơi | h = s = ½·g·t² |
| Thời gian rơi | t = √(2h / g) |
| Công thức liên hệ | v² = 2gh ⇔ v = √(2gh) |
| Quãng đường trong giây thứ n | Δsₙ = ½·g·(2n – 1) |
| Tỉ lệ quãng đường các giây liên tiếp | 1 : 3 : 5 : 7 : … |

--D. Sai số phép đo (ĐV 1.3)--

| Đại lượng | Công thức |
| Giá trị trung bình | Ā = (A₁ + A₂ + … + Aₙ) / n |
| Sai số tuyệt đối từng lần | ΔAᵢ = trị tuyệt đối của hiệu (Ā – Aᵢ) |
| Sai số ngẫu nhiên trung bình | ΔĀ = (ΔA₁ + … + ΔAₙ) / n |
| Sai số tuyệt đối phép đo | ΔA = ΔĀ + ΔA_dc (ΔA_dc = ½ ĐCNN) |
| Sai số tỉ đối | δA = (ΔA / Ā) × 100 % |
| Phép cộng / trừ A = B ± C | ΔA = ΔB + ΔC (cộng **tuyệt đối**) |
| Phép nhân / chia A = B·C hoặc B/C | δA = δB + δC (cộng **tỉ đối**) |
| Cách ghi kết quả | A = Ā ± ΔA hoặc (Ā – ΔA) ≤ A ≤ (Ā + ΔA) |

=F.2. Hằng số và quy ước cần thuộc lòng=

| Đại lượng | Giá trị |
| Gia tốc rơi tự do g | ≈ 9,8 m/s² (thường lấy **10 m/s²** khi đề không ghi) |
| Đổi vận tốc | **1 m/s = 3,6 km/h** |
| Đổi chiều dài | 1 cm = 0,01 m; 1 km = 1000 m |
| Đổi thời gian | 1 phút = 60 s; 1 giờ = 3600 s |
| Đơn vị gia tốc | **m/s²** |

=F.3. Mười điều cốt lõi phải nhớ (ôn trong 5 phút)=

# **Vật lí** nghiên cứu các **dạng vận động của vật chất** và **năng lượng**; phương pháp chính là **thực nghiệm** (5 bước) và **mô hình**.
# **An toàn:** tắt nguồn trước khi cắm/tháo; đúng điện áp định mức; không cầm dây để rút phích; không nhìn tia laser; đồ bảo hộ khi có nhiệt.
# **Sai số dụng cụ = ½ ĐCNN**. Phép **±** cộng sai số **tuyệt đối**; phép **× ÷** cộng sai số **tỉ đối**. Ghi A = Ā ± ΔA.
# **Quãng đường s** = độ dài quỹ đạo (vô hướng). **Độ dịch chuyển d** = vectơ nối đầu – cuối. Luôn có **| d | ≤ s**.
# **Tốc độ** = s/t (vô hướng). **Vận tốc** = **d**/t (vectơ). Tốc độ tức thời = số chỉ tốc kế.
# **Cộng vận tốc** phải cộng **có hướng**; hai vận tốc **vuông góc** dùng **Pythagore**, không cộng đại số.
# Đồ thị **d – t**: **độ dốc = vận tốc**. Đồ thị **v – t**: **độ dốc = gia tốc**, **diện tích = quãng đường**.
# **Gia tốc** a = Δv/Δt (m/s²). **a cùng dấu v → nhanh dần; a trái dấu v → chậm dần.**
# Bốn công thức CĐT BĐĐ: **v = v₀ + at** · **s = v₀t + ½at²** · **x = x₀ + v₀t + ½at²** · **v² – v₀² = 2as**.
# **Rơi tự do** = CĐT **nhanh dần đều** với **v₀ = 0, a = g**: **v = gt** · **h = ½gt²** · **v² = 2gh**; tỉ lệ quãng đường các giây: **1 : 3 : 5 : 7**.
