# Đề cương ôn tập Giữa học kì I – Vật lí 10 (2026–2027)

Tài liệu ôn tập được biên soạn bám sát file gốc **`MA TRẬN ĐẶC TẢ KTGK I L10- 2026.docx`**
(ma trận + đặc tả đề kiểm tra giữa kì I môn Vật lí 10, năm học 2026–2027).

## Sản phẩm

- **`De_cuong_on_tap_Vat_li_10_GK1_2026.pdf`** — đề cương chính thức, 30 trang, có mục lục
  bấm được và bookmark.
- `decuong/` — mã nguồn sinh PDF (ReportLab). Chạy lại bằng:

```bash
python3 -m venv .venv && .venv/bin/pip install reportlab pymupdf
.venv/bin/python decuong/build.py
```

## Cấu trúc tài liệu

| Phần | Nội dung |
| --- | --- |
| 0 | Đọc vị đề thi: cấu trúc, ma trận, 3 túi điểm, phân bổ 50 phút |
| 1 | Lý thuyết trọng tâm Bài 1 → Bài 10 (kèm ví dụ mẫu, mẹo nhớ, bẫy đề) |
| 2 | Sổ tay 26 công thức + cây quyết định + từ khoá đề → công thức |
| 3 | Đề ôn tập mô phỏng khớp 100% ma trận (18 TN + 2 câu Đ/S + 2 TN ngắn + 1 bài toán) |
| 3B | Đáp án, lời giải chi tiết, thang điểm, sổ ghi lỗi |
| 4 | 70 thẻ nhớ nhanh (hỏi – đáp) |
| 5 | 12 lỗi mất điểm, quy trình 4 bước, checklist, bảng tự đánh giá |
| 6 | Trang bỏ túi + lịch ôn 7 ngày |
| Phụ lục | Đặc tả yêu cầu cần đạt tóm lược |

> Lưu ý: file gốc là **ma trận – đặc tả**, không kèm đề và đáp án cụ thể. Vì vậy Phần 3 là
> đề mô phỏng được thiết kế đúng theo phân bổ câu hỏi trong ma trận, kèm đáp án và lời giải
> chi tiết cho từng câu/ý.
