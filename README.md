# Đề Cương Ôn Tập Kiểm Tra Giữa Học Kì I — Vật Lí 10 (Năm học 2026–2027)

Tài liệu ôn tập toàn diện, cô đọng và dễ ghi nhớ nhất dành cho kỳ **Kiểm tra Giữa học kì I môn Vật lí lớp 10 (năm học 2026–2027)**, được nghiên cứu chuyên sâu và biên soạn bám sát **100% từng ô câu hỏi và chỉ báo năng lực** trong văn bản gốc [`MA TRẬN ĐẶC TẢ KTGK I L10- 2026.docx`](./MA%20TRẬN%20ĐẶC%20TẢ%20KTGK%20I%20L10-%202026.docx) (Bộ sách *Kết nối tri thức với cuộc sống* — GDPT 2018).

Biên soạn & Thiết kế lại bằng **TypeScript (React)** và hệ thống thiết kế **Facebook Astryx** (`@astryxdesign/core`).

## 🛠️ Hướng Dẫn Biên Dịch PDF Bằng TypeScript & Facebook Astryx

Cài đặt các gói phụ thuộc và biên dịch file PDF:

```bash
npm install
npx playwright install chromium
npm run build
```

Nếu muốn biên dịch bằng Typst gốc:

```bash
npm run build:typst
```
